1. Введение

Эта обучающая система предназначена для выполнения заданий, оценки ваших навыков и взаимодействия с учителем. В данном руководстве описаны основные функции системы и порядок действий ученика.

2. Авторизация

На странице входа, неавторизованный пользователь может ввести логин и пароль

Если введенные данные были верные, система откроет страницу "Мои задания".

3. Страница "Мои задания"

После входа в систему вы автоматически переходите на страницу "Мои задания". Здесь отображены:

  • Список задач:Заданные учителем для закрепления или проверки знаний;
  • Оценка: итоговая оценка за выполненные задания, выставленная учителем.

Вы можете выбрать любую задачу из списка для перехода к её решению.

4. Решение задачи

После выбора задачи вы попадете на страницу её решения. Здесь вы увидите:

  • Название задачи: заголовок с её именем;
  • Описание задачи: текст с указанием, что нужно выполнить;
  • Визуальное отображение: игровое поле с объектами (стены, зелья, чан и ваш персонаж);
  • Поле для ввода решения:
    список доступных примитивов (например, "влево", "вверх", "вниз", "вправо", "повторить") для создания последовательности действий. Если необходимо удалить действие, необходимо перетянуть в поле "Корзина"

После создания решения нажмите кнопку "Проверить решение", чтобы проверить корректность решения.

Если вы уверены в корректности решения нажмите кнопку "Чтобы ответ поступил учителю"

5. Поле ответа от учителя

В нижней части страницы отображается поле с обратной связью от учителя. Оно содержит:

  • Комментарий: текст с пояснением или рекомендацией;
  • Оценка: баллы, выставленные учителем за решение задачи.

Если ваша задача не выполнена правильно, исправьте ошибки и отправьте решение повторно.
